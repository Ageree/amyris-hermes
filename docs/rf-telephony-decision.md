# Телефония для «Poke-для-России»: исходящие звонки на +7 — решение

> Контекст: мультитенантный ассистент на Vercel **Eve** + LLM **MiniMax-M3**. Агент должен
> сам звонить российским ресторанам / клиникам / заведениям (бронь, запись, вопрос), говорить
> по-русски и вернуть пользователю расшифровку разговора. Онбординг = сайт → телефон → чат для
> RU-пользователей.
>
> **Критерий #1 (pass/fail): провайдер РЕАЛЬНО ставит исходящий голосовой вызов на номера +7
> (стационар И мобильный).** AgentPhone отвалился вживую: «Calls to this destination aren't
> supported». Это и есть фильтр, который режет почти всех западных AI-телефонных платформ.
>
> Дата: 2026-06-26. Источники проверены вживую (web fetch/search), URL — в каждой строке.

---

## 1. TL;DR

- **Победитель — связка «RU SIP-транк + RU речь + наш M3» на базе MTS Exolve (exolve.ru).**
  Exolve — это сам российский оператор (МТС/МТТ), значит +7 (мобильный и стационар), +7 caller-ID
  и рублёвый биллинг гарантированы и санкционно-безопасны; SIP-транк + Voice API + запись отдаём
  своему медиа-стеку, где крутится STT → MiniMax-M3 → TTS. Подтверждено вживую: страница Voice API
  описывает исходящие внешним абонентам, SIP-транк для разработчиков, запись разговоров.
- **Резерв — Voximplant.ru** (ООО «Фастком», RU-сущность). Единственная RU-платформа, где
  BYO-LLM «из коробки»: VoxEngine открывает двусторонний WebSocket из облака → стримит аудио в
  наш бэкенд → MiniMax-M3 (OpenAI-совместимый) подключается как мозг диалога. Чуть дороже и тоже
  требует собрать пайплайн, но меньше своей инфраструктуры (не надо держать Asterisk/FreeSWITCH).
- **Кто МОЖЕТ звонить на +7:** только российские операторы/CPaaS — **Exolve, Voximplant.ru,
  Novofon, Mango, UIS, Sipuni, Telfin, MCN, Beeline-бизнес** — и турнкей RU-роботы
  (**Just AI/JAICP, Robovoice, Neuro.net, MTT VoiceBox, Zvonok**).
- **Кто НЕ МОЖЕТ (дисквалификация по критерию #1 или по доступности для RU-оператора):**
  **AgentPhone** (живой отказ), **Twilio, Telnyx, Plivo, Bland, Synthflow** (гео-блок +7 +
  санкции + нет +7 caller-ID), **Vapi / Retell / Dasha** — сами на +7 не звонят и RU-карту/юрлицо
  не принимают; работают ТОЛЬКО если прицепить к ним российский SIP-транк и платить с не-RU
  сущности. **AudioCodes Voca** — вообще не туда (Teams-инбаунд, нет RU).

**Голосовой слой (русский TTS/STT) — не телефония, а компонент:** лучший русский голос дают
**Yandex SpeechKit** (макс. натуральность), **Tinkoff/T-Bank VoiceKit** (заточен под телефонию
8 кГц, дешёвый STT), **Sber SaluteSpeech** (бесплатный тариф для прототипа). Любой из них
ставится поверх SIP-транка.

## 3. Две жизнеспособные архитектуры

### Архитектура A — турнкей RU voice-AI платформа (с BYO-LLM, если возможно)

**Стек:** Just AI / JAICP (или Voximplant Kit) ведёт телефонию + голос + сценарий; MiniMax-M3
подключается как генератор реплик (JAICP `CUSTOM_LLM`, OpenAI-streaming-совместимый).

- **Усилие:** низкое-среднее. Платформа держит SIP, TTS/ASR, барж-ин, запись. Мы пишем сценарий
  + врезаем M3 на генерацию текста.
- **Контроль:** средний. Диалог оркестрируется DSL платформы; M3 не «мозг» end-to-end, а
  per-turn NLG. Для booking-сценариев это ок, но «живой Poke-разговор» ограничен рамками сценария.
- **Цена:** enterprise/quote (JAICP) либо pay-as-you-go (Voximplant Kit). Минуты ~1.5–3₽ + лицензия.
- **Когда:** если важна скорость до MVP и сценарии узкие (бронь стола / запись к врачу).
- **Минус:** Neuro.net / MTT VoiceBox / Zvonok из этого ряда **не** дают BYO-LLM — там фикс-NLU,
  это против архитектуры Eve+M3.

### Архитектура B — RU SIP-транк + RU речь + наш M3-луп (РЕКОМЕНДУЕТСЯ)

**Стек:** Exolve (SIP-транк + Voice API + аренда +7) → наш медиа-сервер (FreeSWITCH/Asterisk
или Voximplant.ru-WebSocket вместо своего медиа) → STT (Yandex SpeechKit / Tinkoff VoiceKit,
8 кГц, стриминг) → **MiniMax-M3** (OpenAI-совместимый, диалог) → TTS (Yandex/Tinkoff) → обратно
в звонок. Запись + транскрипт пишем сами (или Exolve Transcription API).

- **Усилие:** среднее-высокое. Надо собрать и держать STT↔M3↔TTS-луп (барж-ин, VAD, латентность,
  телефонный кодек 8 кГц). Voximplant.ru снимает «держать свой Asterisk» (медиа стримит их облако
  по WebSocket), но логику луп-а всё равно пишем мы.
- **Контроль:** максимальный. M3 — настоящий мозг диалога, никакого потолка сценария → честный
  Poke-стиль. Полный доступ к сырому аудио → транскрипт «бесплатно».
- **Цена:** самая низкая на минутах. Exolve ~1.5–3₽/мин; речь (STT+TTS) ~копейки/звонок; +7 номер
  ~сотни ₽/мес; плюс токены M3. **100 польз. ≈ $17–35/мес + номера; 1000 ≈ $170–350/мес + номера**
  (телефония) + инференс M3.
- **Когда:** наш случай. Мультитенантный SaaS, нужен живой русский разговор, экономика на масштабе,
  санкционная чистота.

**Вывод:** B — целевая. Чтобы срезать сложность медиа-сервера, **резервный вариант B′ =
Voximplant.ru** (WebSocket-BYO-LLM вместо своего FreeSWITCH). A держим как fallback, если луп-латентность
M3 окажется неприемлемой и придётся отдать диалог сценарному движку.

## 4. Победитель + резерв + интеграция в Eve

### ★ Победитель: MTS Exolve (телефония) + Yandex SpeechKit/Tinkoff (речь) + MiniMax-M3 (мозг)

**Почему:** единственный класс, который проходит критерий #1 без оговорок и без санкционного риска —
это **российский оператор**. Exolve — МТС/МТТ, +7 мобильный И стационар = его домашняя сеть, +7
caller-ID штатно, рублёвый биллинг, регистрация юрлица/ИП в тот же день. Voice API + SIP-транк
(подтверждено вживую: «исходящие звонки внешним абонентам», «SIP-транк API-платформы» для
разработчиков, «запись разговоров»). Лучшая комбинация «дёшево + точно дозвонится + мы владеем медиа».

### ★ Резерв: Voximplant.ru

**Почему:** RU-сущность (ООО «Фастком»), +7 outbound — её исторический рынок, аренда +7 для
caller-ID, нативный Yandex/Tinkoff TTS, **и единственная RU-платформа с задокументированным
BYO-LLM**: VoxEngine открывает двусторонний WebSocket из облака, стримит аудио в наш бэкенд, мы
гоняем STT→M3→TTS и возвращаем медиа. Берём, если не хотим держать свой FreeSWITCH или если у
Exolve затык с медиа-форком в реальном времени. Открытый вопрос — пост-санкционная биллинг-сущность,
не возможности.

### Эскиз интеграции в Eve

1. **Триггер.** Агент Eve вызывает наш tool `place_call` (`defineTool`, Zod-схема):
   `{ phone: "+7…", goal: "забронировать стол на 2 на 19:00", lang: "ru" }`. Сетевую логику держим
   в `lib/telephony.ts` (чистый хелпер → network-free unit-check), tool-файл тонкий I/O.
2. **Старт звонка.** Хелпер дёргает Exolve Voice API (или Voximplant.ru `callPSTN`) с нашим
   арендованным +7 как caller-ID; медиа-сессия поднимает STT-стрим (Yandex/Tinkoff, 8 кГц).
3. **Луп диалога.** Партиалы STT → системный промпт + цель → **MiniMax-M3** (OpenAI-совместимый
   эндпоинт; у нас уже есть рабочий путь через OpenRouter/`AI_GATEWAY`) → текст → TTS → в звонок.
   Барж-ин по VAD. M3 говорит по-русски, ведёт бронь/вопрос.
4. **Завершение + read-back.** По `END`-webhook забираем запись + полный транскрипт (свой STT или
   Exolve Transcription API), агент Eve резюмирует исход («Стол на 19:00 подтверждён, спросили имя —
   передал ваше») и шлёт пользователю в чат. Транскрипт прикладываем как артефакт.
5. **Мультитенантность.** На тенанта — свой арендованный +7 (или пул) для caller-ID; токены M3 и
   минуты Exolve тарифицируем по тенанту (как уже делаем в Hermes-флоте через env-инъекцию).

## 5. Открытые риски

- **Санкции / платёж (главный для не-RU вендоров).** Vapi/Retell/Dasha/Twilio/Telnyx/Plivo/Bland/
  Synthflow — US/EU-сущности, RU-карту и RU-юрлицо не принимают, OFAC-скрининг. Для них +7 либо
  гео-блок, либо «технически да, но оператор не зарегистрируется/не заплатит». **Берём только
  российских операторов** → риск снят by design. Exolve/Voximplant.ru/Novofon — рубли, RU-юрлицо.
- **Caller-ID и закон.** Подмена произвольного номера в РФ незаконна; показывать можно ТОЛЬКО
  реально арендованный у оператора +7. Это нормально и ожидаемо (Exolve per-SIP-ID CallerID).
  Аренда +7 требует RU-документов (стандартный телеком-KYC) — не мгновенный self-serve.
- **38-ФЗ / согласие на робозвонки.** Массовый автодозвон без согласия абонента регулируется;
  но наш кейс — **звонок бизнесу по поручению конкретного пользователя** (бронь/вопрос), а не
  холодный обзвон физлиц. Всё равно: (1) звоним заведениям, не потребителям; (2) бот должен
  представляться; (3) не использовать как спам-дайлер. Юридически свериться перед продом.
- **Качество разговора (латентность луп-а).** STT→M3→TTS на телефонном 8 кГц — узкое место по
  задержке и барж-ину. Меряем time-to-first-audio; если M3-луп тормозит — fallback на Архитектуру A
  (сценарный движок с M3 только на NLG) или на realtime-коннектор Voximplant.
- **`unclear`-строки (честно).** Telnyx/Plivo +7 — не подтверждён положительно (gated), помечены
  `?`. MCN/Beeline — программный call-API/webhooks из публичных доков не подтвердились. Dasha — нет
  доказательств текущего +7-терминирования и RU-биллинга (low-confidence). Эти НЕ закладывать в план
  без живого пробного звонка.
- **Зависимость от голос-слоя.** Yandex SpeechKit/Tinkoff/Sber — RU-сущности, рубли, без санкц.
  риска; но это второй вендор в стеке. Tinkoff TTS — только для юрлиц (founder заводит ИП/ООО).

## Проверка победителя (adversarial)

**Вердикт: ПОБЕДИТЕЛЬ ПОДТВЕРЖДЁН (MTS Exolve).** Попытка опровергнуть 3 жёсткие претензии
вживую (web fetch, 2026-06-26) — ни одна не опровергнута, найдена одна честная оговорка.

- **(1) Исходящие на +7 — ✅ ПОДТВЕРЖДЕНО.** Voice API и SIP-транк прямо описывают «исходящие
  звонки внешним абонентам» («оплачиваете только исходящие звонки внешним абонентам»). Метод
  `MakeVoiceMessage` «запускает автоматизированный обзвон». Exolve — сам RU-оператор (МТС/МТТ),
  так что +7 (мобильный И стационар) — его домашняя сеть. Не SMS-only, не inbound-only.
- **(2) Натуральный русский голос — ✅ ПОДТВЕРЖДЕНО.** Voice API принимает параметр `tts`
  (голос/язык/скорость/эмоция/громкость), **15 русских голосов** с эмоциями. Плюс отдельный
  продукт «Синтез речи». Свой Yandex/Tinkoff TTS поверх SIP — тоже опция.
- **(3) Программный outbound-API + BYO-M3 — ✅ ПОДТВЕРЖДЕНО, с оговоркой.** Outbound-API есть
  (`MakeVoiceMessage` + `SetCallRecordState` для записи). **ВАЖНАЯ ОГОВОРКА:** документированный
  Voice-API-метод — это **односторонний робозвон** (предзапись ИЛИ онлайн-синтез TTS), **без
  стриминга двустороннего аудио** — в него M3 пер-тёрн не воткнёшь. Настоящий Poke-стиль BYO-M3
  идёт **через SIP-транк** (Asterisk/3CX/FreePBX/Avaya/Cisco — указаны прямо) в наш медиа-сервер,
  где realtime RTP двусторонний. Это РОВНО то, что говорит таблица («✅ API+SIP / **BYO via SIP**»)
  и Архитектура B — overclaim'а нет. То есть: «звонилка» через API, «мозг M3» через SIP+свой медиа.
- **Санкции / регистрация — ✅ безопасно, но НЕ self-serve.** Домашний RU-оператор (МТС), рубли,
  никакого OFAC/западного платёжного рельса. НО регистрация требует **бизнес-аккаунта юрлица/ИП
  с идентификацией через Госуслуги** — не мгновенный self-serve с физлица. Это ожидаемый телеком-KYC
  и совпадает с риском «аренда +7 требует RU-документов» в §5. Основатель заводит ИП/ООО → проходит.

**Итог:** критерий #1 победитель проходит без оговорок; единственная уточнённая деталь — что
BYO-LLM-луп строится на SIP-транке, а не на одностороннем `MakeVoiceMessage`. Резерв (Voximplant.ru)
менять не нужно. Замены победителя не требуется.
